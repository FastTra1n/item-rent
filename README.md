# Сервис аренды вещей

## Назначение

Консольное приложение для аренды бытовых вещей, электроники и инструментов. Проект позволяет пользователю найти нужную вещь и забронировать её на определённый срок, не покупая её.

## Целевая аудитория

1. **Арендаторы**: люди, которым необходимы инструменты, различного рода техника или спортивный инвентарь "здесь и сейчас".
2. **Владельцы**: владельцы вещей, которые хотят получать доход от сдачи предметов в аренду.

## Предметная область

Приложение относится к сфере аренды и шеринг-экономики. Приложение позволяет удобно искать товары, проверять доступность конкретных предметов на выбранные даты, расчитывать стоимость, а также установливать статус бронирования.

## Основные сущности

- **Вещь**: Название, категория, стоимость аренды, залоговая стоимость, текущий статус доступности вещи.
- **Владелец**: Имя владельца вещи, контактные данные, рейтинг.
- **Арендатор**: Имя пользователя, контактные данные, статус подтверждения аккаунта.
- **Бронирование**: Ссылки на владельца, арендатора и арендуемую вещь, дата начала и окончания аренды, итоговая стоимость, статус заявки.
- **Категория**: Группировка вещей по своему назначению (инструменты, электроника, спорт, туризм).

## Основные функции

- Отображение полного списка вещей, доступных для бронирования
- Поиск конкретной вещи по названию
- Проверка доступности конкретной вещи для бронирования
- Бронирование конкретной вещи на указанные даты
- Отмена существующей брони
