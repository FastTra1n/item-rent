## Назначение

Консольное приложение для аренды бытовых вещей, электроники и инструментов. Проект позволяет пользователю найти нужную вещь и забронировать её на определённый срок, не покупая её.

## Основной функционал

- Отображение полного списка вещей, доступных для бронирования
- Добавление новой вещи для аренды
- Поиск конкретной вещи по указанному названию
- Проверка доступности конкретной вещи для бронирования
- Бронирование конкретной вещи на указанные даты
- Отмена существующей брони
- Отображение списка всех пользователей системы
- Добавить нового пользователя в систему
- Нахождение конкретного пользователя по его уникальному идентификатору

## Используемые технологии

- Python 3;
- Django 5.2 - веб-фреймворк;
- HTML - разметка веб-страниц;
- CSS и Bootstrap 5.3 - оформление страниц;
- pytest - автоматизированные тесты;
- ruff - проверка качества кода.

## Целевая аудитория

1. **Арендаторы**: люди, которым необходимы инструменты, различного рода техника или спортивный инвентарь "здесь и сейчас".
2. **Владельцы**: владельцы вещей, которые хотят получать доход от сдачи предметов в аренду.

## Предметная область

Основными объектами предметной области являются:

- Вещь;
- Бронирование;
- Пользователь.

Приложение относится к сфере аренды и шеринг-экономики. Приложение позволяет удобно искать товары, проверять доступность конкретных предметов на выбранные даты, бронировать вещи, расчитывать стоимость, а также установливать статус бронирования.

- `owner` – владелец вещи (объект `User`);
- `name` – название вещи;
- `price` – цена аренды вещи;
- `deposit` – залоговая стоимость вещи;

### User – клиент

Объект `User` представляет пользователя системы.
Основные атрибуты:

- `id` – уникальный идентификатор;
- `name` – имя пользователя;
- `phone` – контактный номер.
- `rating` – рейтинг пользователя.

- `from_data()` – создание объекта `User` из набора данных;
- `__str__()` – строковое представление пользователя.

### Booking – аренда

Объект `Booking` связывает вещь (`Item`) и клиента (`User`).
Основные атрибуты:

- `id` – уникальный идентификатор аренды;
- `item` – арендуемая вещь (объект `Item`);
- `user` – пользователь-арендатор (объект `User`);
- `start_date`, `end_date` – период аренды;
- `is_cancelled` – признак отмены аренды.
  Основные методы:
- `cancel()` – отмена аренды;
- `__str__()` – строковое представление аренды.

## Страницы веб-интерфейса

- `/` - главная страница: описание приложения и навигация (view-функция `index()`);
- `/items/` - каталог вещей: объекты `Item` из `data/items.json` (view-функция `items_list()`);
- `/items/<int:item_id>/` - страница конкретной вещи (view-функция `item_detail()`);
- `/bookings/` - список бронирований: объекты `Booking` из `data/bookings.json` (view-функция `bookings_list()`);
- `/bookings/<int:booking_id>/` - страница бронирования (view-функция `booking_detail()`).

## Основные операции

### Работа с вещами

- Добавление новой вещи в базу;
- Поиск существующей вещи по названию;
- Отображение полного списка вещей из базы.

### Работа с пользователями

- Добавление нового пользователя в базу;
- Поиск пользователя по его уникальному ID;
- Отображение полного списка пользователей системы.

### Работа с бронированиями

- Проверка возможности бронирования вещи на указанный период;
- Создание нового бронирования;
- Отмена существующего бронирования;
- Получить текущий статус бронирования.

## Хранение данных

Данные приложения хранятся в отдельных JSON-файлах:

- `data/items.json` - вещи, доступные для бронирования;
- `data/bookings.json` - список бронирований;
- `data/users.json` - пользователи системы.

При загрузке данные из JSON преобразуются в соответствующие им объекты `Item`, `Booking` и `User`.

## Назначение модулей

### `main.py`

Основная точка входа в приложение, отвечающая за запуск приложения, отображение меню с выбором доступных опций и вызов методов с логикой из основных модулей.

### `rently/`

Пакет настроек Django-проекта:

- `settings.py` - настройки проекта;
- `urls.py` - маршрутизация верхнего уровня;
- `asgi.py`, `wsgi.py` - точки взаимодействия с сервером.

### `homepage/`

Django-приложение главной страницы:

- `views.py` – функция `page()` (общий HTML-каркас) и view-функция `index()`;
- `urls.py` – маршрут главной страницы.

### `items/`

Django-приложение каталога вещей:

- `views.py` – view-функции `items_list()` и `item_detail()`;
- `urls.py` – маршруты приложения;

### `bookings/`

Django-приложение системы бронирования:

- `views.py` – view-функции `bookings_list()` и `booking_detail()`;
- `urls.py` – маршруты приложения;

### `models/`

Классы предметной области и функции работы с ними:

- `items.py` – класс `Item` и функции работы с вещами;
- `users.py` – класс `User` и функции работы с пользователями;
- `bookings.py` – класс `Booking` и функции работы с бронированиями.

### `storage.py`

Отвечает за подгрузку/сохранение информации о вещах, бронированиях и пользователях в системы.

### `utils.py`

Содержит в себе вспомогательные функции:

- `input_int()` - безопасный ввод целого числа;
- `input_date()` - безопасный ввод даты.

### `tests.py`

Содержит автоматизированные тесты для проверки корректности выполняемой логики.
